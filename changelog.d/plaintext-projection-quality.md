### Fixed
- Syntax highlighting emits one span per RUN of same-class tokens instead of one per token. A lexer routinely splits one visual atom into several tokens of the same type — Crystal's `puts "hi"` arrives as `"`, `hi`, `"` and an empty one — so the output carried four elements (one of them `<span class="hljs-string"></span>`, with no content) where one belongs. The docs site loses 9.6% of its highlight spans and 68 KB of HTML, and because `strip_html` inserts a space at a tag boundary, the search index and feed summaries now read `puts "hi"` instead of `puts " hi"`. Rendered text is unchanged
- Elements marked `aria-hidden="true"` no longer leak into plain-text projections (search index, feed summaries, excerpts, the `strip_html` filter). A screen reader skips them and so should every text extraction: `insert_anchor_links` put a 🔗 in the index after every heading, and `[highlight] line_numbers` indexed `1 2 3 4 …` alongside the code
