### Fixed
- Custom heading ids may start with a digit: `## 1. 프로젝트 만들기 {#1-create-a-project}` now sets that id instead of rendering the brace block as literal text next to an auto-generated slug (#792). The id grammar required a leading letter — the HTML 4 rule — while hwaro's own auto-slugs have always produced digit-leading ids like `1-create-a-project`, so a translated numbered heading could not pin the anchor its English original got. Ids may now begin with any word character (letter in any script, digit, `_`), which is what HTML5 allows; the same widening applies to the `#id` token of a `{#id .class key=val}` attribute block, so both mechanisms accept exactly the same ids
