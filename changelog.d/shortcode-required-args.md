### Added
- Built-in shortcodes warn when a required argument is missing. `{{ codepen(id="abc") }}` (no `user`) rendered a well-formed iframe pointing at `https://codepen.io//embed/abc`, `{{ gist(id="abc") }}` one at `https://gist.github.com//abc.js`, and `{{ figure() }}` an `<img src="">` — a dead embed on the published page, exit code 0, nothing in the log. `youtube`, `vimeo`, `gist`, `tweet`, `codepen` and `figure` now name the missing slot and the correct usage; a blank value counts as missing, and a user template in `templates/shortcodes/` (including one overriding a built-in) defines its own contract and is never checked
