### Fixed
- `hwaro build --stream` no longer corrupts feeds and the search index. Streaming released each batch's rendered body, and the generators that read it back fell through to a markdown-only re-render of the source — so `search.json` and every feed carried raw `{% shortcode %}` markup, unresolved `@/` links and no anchor links, contradicting the documented "output is identical whether streaming is enabled or not". The release is now skipped when a search index or any feed will read the content back, which also drops a second full markdown pass per page (a 600-page corpus built 38% faster)
